当时的部署地址（现已更新为其他原型）：[城南八周](https://three-weekends-yuki.yuki-uix.chatgpt.site/)。同一站点从「三个周末」更新；实现见 [web/README](../web/README.md)。

## 为什么更换核心循环

用户对 v0.1 的直接反馈是「不好玩，没有养成系的感觉」，并明确选择「养角色：从生疏到熟练，逐渐形成能力和身份」，随后补充「能力应该决定了可以触发什么事件（如果 MVP 超了的话提醒我）」。

此前三回合只验证一次性项目排程，作品完成后几乎没有使用成长的时间。加叙事和像素 UI 未解决这一缺口。v0.2 调整玩法本身，保留少前情、具体行动、事实记录与无统一人生排名。

书店与创作是沿用现有场景的两个验证样本，不代表用户已经确认喜欢画画或书店题材。不恢复此前 20 事件、教育、国家与全人生系统。

## 必须跑通的循环

```mermaid
flowchart LR
    A[练习眼前的小事] --> B[长出具体本领]
    B --> C[能力触发新的事件]
    C --> D[独立完成实际任务]
    D --> E[继续练习与形成身份]
    E --> F[使用身份承担不同责任]
```

玩家应能说出「我原来做不到什么，现在做到了；这让我接下来想做什么」。经验和余额上涨本身不足以通过验收。自动测试也不证明趣味性。

## 这一版的边界

- 一个角色、同一条街、八周，每周一次行动。
- 两项能力：书店事务、街巷创作，各 0–4；基础练习增加本领，实际任务使用本领。
- 四个条件事件，均有实际前置条件、触发记录和来源。只把已触发的机会放入行动列表，下一步条件在角色卡预览。
- 一个资金约束；¥480 / ¥180 两种起点，默认 ¥480。所有金额均为虚构演示参数。
- 独立任务留下实际成果；身份改变后续任务职责、场景、收入和头像细节。
- 当前一局本地存档、结算反馈、成长记录、成果阅读、重玩。v0.1 记录保留原键，v0.2 单独保存。

## 事件与能力的关系

| 条件事件 | 触发条件 | 实际选择与后果 |
| --- | --- | --- |
| 陈姐请你独立看店 | 书店事务达到 2，上手 | 可接下值班；首次完成留下独立交接记录，之后可重复接班 |
| 早餐摊的招牌委托 | 街巷创作达到 2，上手 | 可画招牌；首次完成后能查看实际挂出去的招牌 |
| 策划自己的周末书桌 | 书店事务达到 4，且独立值班过 | 独立策划主题书桌，形成「书店搭档」身份；以后可以负责自己的书桌 |
| 把散页做成街巷小册 | 街巷创作达到 4，且完成过招牌委托 | 做出《住在这里》，形成「街巷画手」身份；以后可以接插画约稿 |

条件在本周结算后检查，事件下一周可行动。邀请持续有效；没有新增截止日。先练满再做实际任务，也会按真实顺序触发身份机会。

两条路线最早均在第六周形成身份，留下第七、八周使用它。八次行动不足以完成两条完整身份线，玩家可以深入一项，也可两边尝试。末周才达标的机会会记入记录，但不冒充本局仍可操作的内容；结束页明确是试玩暂停。

## 行动与代价

| 行动 | 每次净资金变化，含 ¥80 日常开销 | 成长或用途 |
| --- | --- | --- |
| 跟陈姐整理书架 | +¥120 | 书店事务 +1，上限 4 |
| 练习街巷速写 | −¥120 | 街巷创作 +1，上限 4 |
| 独立看店 | +¥240 | 使用已学能力；保留首次任务事实 |
| 画街角招牌 | +¥120 | 使用已学能力；保留首次任务事实 |
| 策划周末书桌 | −¥80，仅一次 | 身份、书桌成果；后续负责书桌净 +¥280 |
| 制作街巷小册 | −¥80，仅一次 | 身份、小册成果；后续插画约稿净 +¥180 |

书店线更容易积蓄；创作线留下不同作品和职责。这里不承诺所有策略同样有效：明确目标下可以有局部更优做法，但不会把不同本领与作品都折成一个人生分数。若玩家仍只感到钱多就更好，应继续修成长用途和成果反馈，不能以无总分自证多种追求已经成立。

## 验收与扩展窗口

1. 初始没有独立任务，能力达到门槛后才出现；事件记录可以追溯到练习及实际任务。
2. 两条路线都能完整经历「练习—新事件—独立使用—身份—身份后再行动」。
3. 第一次任务、重复任务、身份后的职责有可辨认的差异；成果不是提前写好的虚构经历。
4. 资金不足不抹掉已学能力或已来的邀请，基础工作仍可继续；无负数、重复结算或刷新重抽。
5. 手机能看到能力与下一机会，完成成果后可以实际查看，刷新恢复当前阶段。

当前保留 skill / action / opportunity 的稳定 ID、触发门槛、实际解锁时间、来源事件、身份事实与文字快照。够用时再加入一个新能力或事件，不预建通用职业、技能树或随机剧情引擎。

范围已经从三回合排程调整为八次角色成长，是明确的 MVP 修订。后续若需要第三条能力、复杂职业树、关系系统或完整一生，需先单独讨论范围。Sharing 与共同在场继续后置。

## 下一轮已确认方向，尚未实现

用户再次试玩后认为 v0.2 仍不好玩，要求综合参考养成游戏设计。随后提出先从单个国家切入、走顺后通过参考文件扩展，并明确选择「大学到初入职场：能力、人际和职业方向逐渐形成」。下一轮据此采用中国背景；现有线上仍是本文件上文记录的 v0.2 样本。

目前确认的是背景与成长阶段，不把当前书店/创作、八周预算或一整套大学到退休模拟直接移植为新需求。具体切片与事件先经纸面体验设计；下一版的数量预算和边界见 [中国首版 MVP 范围提案](china-mvp-scope.md)，复评与一手参考见 [游戏设计报告](lead-game-design-review.md)。本轮未改线上实现。

最新纠偏：用户认为求职主题太苦，希望体验快乐的大学几年。下一版范围已以 [轻松大学生活提案](china-mvp-scope.md) 为准，前一份毕业到入职的节点预算不再作为当前建议。当前线上 v0.2 保持不变。
