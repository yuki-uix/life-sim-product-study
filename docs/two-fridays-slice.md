# 连续八天：今日安排试玩

当前入口 `/fridays/`，仍从10月11日第一次周五走到18日第二次周五。使用独立的 `campus-fridays.save.v2` 存档。首页直接进入当前试玩，旧版秋季移至 `/autumn.html` 供对比。

上一版失败在机制：固定场景跳接，周中两次准备只收集标签；不少处理办法给出同一场放映、相似散场。没有重复投入形成的进度，也没有可以规划、可能赶不上的具体目标。v2据用户反馈改成连续日期里的今日安排。

## 已实现范围

- 一个虚构中国校园，三位同学，连续八个日期。
- 第一晚选择看片或帮忙，各是一次实际体验。之后周六至周四，每天为自己留一段课余，从看片、练设备、相处或休息中安排一件事；它不代表全天只能做一件事。
- 选片、动手各0—4。初次体验加六段课余，总计最多七次能力投入，无法同时练满两项。
- 到2便能亲自试排主题片单，或借钥匙独自试放。这些是当周可执行的新活动；独立策划需要实际做过片单，开放教室需要实际试过现场，不只看数值。
- 周五计划从开头预告条件：选片4加真实片单可独立策划；动手4加试场可开放教室；2+2可和小满分工；两次与阿禾相处能收到宿舍私人看片邀请。普通观众始终可选。
- 独立策划亲自决定主题、节目和开场时间；开放教室决定空间与接待；合作保留玩家和小满各自的工作归属；私人邀约改变地点和共同度过这一晚的人。
- 有明确、可规划的取舍：长片82分钟，晚场距关门只剩65分钟，确实放不完；接待更多人会占去自己看片时间；了解并约好林野帮忙能改变现场分工。不会统一把未完成写成圆满。
- 日常简短记录和关键剧情分开。日期、安排、能力与未来条件明确呈现；最新记录在最上方。每次安排后直接进入下一日期，不需要再点一次继续生活。

## 实现边界

`engine.js` 保存日历、技能、实际作品、相处与当晚计划，提供透明条件预告及结果事实；`story.js` 提供日常和状态相关的叙述；`app.js` 提供今日安排、日历、预告和记录。存档严格重放验证。UI使用原有克制像素字体与原生校园插图。

不扩完整学期、金钱/体力/成绩压力、恋爱网络、自由生成聊天、其他国家或分享系统。当前数值只是小片段内的玩法规则，不代表真实人的成长速度。验证重点是玩家能否先产生目标、据条件安排几天，并看见安排造成的具体差异。
