# 大学慢慢来 · 一个秋天

[在线试玩](https://three-weekends-yuki.yuki-uix.chatgpt.site/)。v0.5 在九月一日至十一月三十日的连续校园生活中，加入可见的能力阶段、玩家主动发起并持续准备的小事，以及准备和能力共同开启的后续剧情。虚构中国南棠大学，日历独立推进，近期重心持续作用，普通记录自动出现，少量剧情才暂停等待决定。

这是节奏验证片段，只有入学后的三个月。完整大学四年、其他学制、更多国家与 sharing 后置。

## 本地运行

```sh
cd web
npm run dev
```

打开 `http://127.0.0.1:4173/`。纯 HTML/CSS/JavaScript，无第三方运行依赖，`dist/` 是源码，无需构建。

```sh
npm test
```

26 项日历、养成与迁移测试覆盖持续安排与独立时间、每周记录的实际投入来源、能力与相识、剧情暂停、错过窗口、拒绝参与、后续回响、存档恢复、收藏、日期边界，并验证主动项目、两条后续剧情的能力门槛、合作与独立参与、旧存档保留；原三场剧情的 27 种选项组合继续保留。历史 v0.3 的 22 项检查保留为 `npm run test:legacy`，不计为新版测试。

## 玩法与范围

- 选一个近期课余重心：随心过、常去社团、散步记录、和室友待着。安排会一直持续，可以调整，不用每周重新点击。
- 点击开始，日历自动前进；默认每模拟日 1.6 秒，可暂停、使用 1/2/4 倍速，或快进至下一次成长、准备完成或待答剧情。快进仍经过每一天并保留期间记录。
- 每七天按实际占用时间最多的重心写一条短记录，另有八条校园、天气和季节日常。普通日子不会强制发纪念物或要求领取成果。
- 记录、张罗随实际投入时间渐渐熟练；持续散步或参与社团，才会认识相关人物、在相应时间窗口遇到两场条件剧情。另有一场共同宿舍事件；同一事件也会回应室友相处、随心生活的实际习惯。
- 特殊剧情暂停日历；选择写回当日记录，回到日常后可继续时间，没有统一成果页。原三场剧情加两条主动项目后续，允许不参加；没有触发的剧情不阻碍时间。
- 能力达到入门后，可以主动开始「拍一组校园照片」或「筹一场小放映」；需要七天对应日常实际推进，换重心会暂停并保留进度。完成准备且达到第二阶段能力，才可能在时间窗口里遇到照片墙或自办放映；第三阶段多出独立安排的参与方式。点击开始不发成果、不加点。
- 能力面板说明已经能做什么、离下一阶段还有多久；出现新能力或完成准备时暂停，给玩家决定接下来怎么做的机会。
- 日常和收藏均最新在上；翻阅旧日志时保持阅读锚点，新内容只提示条数，剧情选择后回到最新记录。
- 所有经历与主动收藏分开；给某条记录加星才进入收藏，不自动生成奖品或精选回忆。
- 查看人物、自己或重开确认时暂停；切到其他标签页也暂停。重新打开停在保存日期，不计算离线时间。
- 仍为两项本领、三位同伴。没有资金、压力条、求职、课程表或人生排名。

## 文件

- `dist/calendar-content.js`：四个持续重心、周记、季节记录、三场条件剧情、后续回响与日期文案。
- `dist/calendar-engine.js`：独立日历、时间积累、剧情条件、人物相识、选择与收藏、严格命令重放校验。
- `dist/app.js`：时间控制、持续重心、日常时间线、剧情面板、人物/成长查看与本地保存。
- `dist/campus-art.js`、`dist/styles.css`：沿用克制像素视觉，本地字体与原生 SVG。
- `tests/calendar.test.mjs`、`tests/growth.test.mjs`：14 项日历与 12 项养成/迁移测试。
- `dist/calendar-engine-v4.js`、`dist/calendar-content-v4.js`：只用于严格核验旧存档的原规则，不把旧经历改写成做过新项目。
- `dist/engine.js`、`dist/content.js`、旧测试：保留的 v0.3 历史实现，当前入口不加载。
- `.openai/hosting.json`：复用原 Sites 身份与静态目录。

## 存档与扩展

当前键 `campus-slowly.save.v5`。读取到 v0.4 记录时，先用保留的旧规则严格验证，再接续日期、能力、人物、文字、事件 ID 与收藏；原 `campus-slowly.save.v4` 保留不覆盖。旧 v1/v2/v3 也保留。只保存到当前浏览器。存档包括日历、持续投入、事件事实和文字快照、操作记录与收藏。恢复时重放核对，避免日期、本领、人物、后续剧情互相矛盾；已有文字快照保留。坏存档不会被读取过程自动覆盖，用户可明确重开。

国家内容、日历与通用规则分开。后续分享可从事实日志与收藏读取，本轮未实现分享、多用户、全球随机出生或四年内容。

## 字体与发布

本地提供 [TakWolf / Fusion Pixel Font](https://github.com/TakWolf/fusion-pixel-font) 2026.10.25 的 12px proportional 简体字形，OFL 与上游组件许可保留于 `dist/fonts/`。校园与人物为本项目原生 SVG。

Sites 使用独立部署源仓库，`web/` 是本 GitHub 仓库的同版应用源。复制至 Sites 检出，经 source helper 推送、打包，再用原生工具发布。沿用既有网址与访问范围；本地修改不会自动上线。
