# 大学慢慢来 · 大一试玩

[在线试玩](https://three-weekends-yuki.yuki-uix.chatgpt.site/)。v0.3 是轻松大学生活的第一个可玩切片：虚构的中国南棠大学，大一秋春两个学期、六次主要选择、三位可相识的同伴，结束时翻开按实际经历留下的纪念册。

四年是故事背景与后续方向，本次只有大一两学期可玩；三年、五年及更多国家尚未开放。范围见 [大学生活提案](https://github.com/yuki-uix/life-sim-product-study/blob/main/docs/china-mvp-scope.md)。

## 本地运行

```sh
cd web
npm run dev
```

打开 `http://127.0.0.1:4173/`。本地静态服务需要 Python 3。应用为纯 HTML/CSS/JavaScript，无第三方运行依赖，源文件直接位于 `dist/`，无需构建。

```sh
npm test
```

22 项 Node 内置测试覆盖开局、学期阶段、六次选择结束、能力参与方式、实际回忆引发的邀请、同伴来源、重复与过时操作、存档严格重放和历史文字快照。枚举 436 个可达状态、264 条完整路线，14 种选择均可到达，没有无路可走的局面。测试不证明游戏好玩。

## 这一段怎样玩

- 每学期安排两件具体日常，同一活动不重复占用两段时间。
- 秋天的放映与春日校园节照常发生；本领改变参与方式，和同伴做观众始终可选。
- 「记录」与「张罗」在实际日常中增长；不计算幸福总分、收入排名、求职或考试结果。
- 春天的特殊邀请需要真实的秋天经历，只有本领分数不够；同伴与旧物也会回应实际选择。
- 回忆、同伴卡和纪念册可打开查看；只有真正选过的事会进入自己的经历。
- 每次选择后保存当前阶段。数字键 1–6 可选活动，Esc 关闭弹窗；重新开始前先确认。

## 文件

- `dist/content.js`：中国校园样本、学制/试玩配置、人物、本领、14 种选择、回忆元数据和纯叙事函数。
- `dist/engine.js`：学期进程、条件检查、成长与共同经历、因果来源、严格重放校验；没有网络与随机结算。
- `dist/app.js`：场景、活动、结果、人物回忆、纪念册、菜单与本局保存恢复。
- `dist/campus-art.js`：校园地点、像素头像、纪念物的原生 SVG，无远程图片。
- `dist/styles.css`：桌面与手机界面、焦点、弹窗与减少动画支持。
- `tests/engine.test.mjs`、`tests/story.test.mjs`：13 项规则检查与 9 项叙事一致性检查。
- `.openai/hosting.json`：复用原 Sites 身份与静态目录。

## 记录与扩展边界

v0.3 使用 `campus-slowly.save.v3`，记录只存在当前浏览器，不上传；旧 `three-weekends.save.v1` 与 `chengnan.growth.save.v2` 保留，不伪造迁移成新校园经历。坏存档不会在读取失败时被自动覆盖。

每个已发生事件保存选择、学期、当时能力、实际同伴、回忆 ID、来源事件、叙事与文字快照。纪念册从这些事实读取，不能补写未参加的活动。学制年数独立保留，但只有当前样本的两学期内容可运行，不生成空白后续学期。未来分享与国家扩展单独评估。

## 字体与发布

本地提供 [TakWolf / Fusion Pixel Font](https://github.com/TakWolf/fusion-pixel-font) 2026.10.25 的 12px proportional 简体字形，OFL 与上游组件许可保留于 `dist/fonts/`。人物、校园和纪念物为本项目独立 SVG；没有实时 AI 生成服务。

Sites 使用独立部署源仓库，`web/` 是本 GitHub 仓库的同版应用源。复制到 Sites 检出后，经 source helper 推送精确源码、打包，再用原生工具发布。站点沿用原地址与访问范围；本地文件变化不会自动上线。
