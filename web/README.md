# 城南八周 · 文字养成 RPG

[在线试玩](https://three-weekends-yuki.yuki-uix.chatgpt.site/)。v0.2 用角色养成替代 v0.1「三个周末」的一次性排程：从练习到上手，能力触发真实新事件，实际使用后再形成身份，并有时间继续使用成长结果。

单页 HTML/CSS/JavaScript，无第三方运行依赖；源文件直接位于 `dist/`，无需构建。范围与四个条件事件见 [当前 MVP](../docs/mvp-minimal.md)。试玩题材是验证样本，不是完整人生模拟。

## 本地运行与验证

```sh
cd web
npm run dev
```

打开 `http://127.0.0.1:4173/`；本地静态服务需要 Python 3。

```sh
npm test
```

25 项 Node 内置测试覆盖成长链、两条路线第六周身份与后续使用、能力触发事件及来源、资金不足与恢复、先练后用、重复任务、身份去重、不可变输入、坏存档、文字快照、场景与实际经历一致性。已走查两条完整八周路线、身份后任务、成果弹窗、刷新恢复、数字键及 390×844 手机布局；手机无横向溢出，浏览器未见警告或错误。测试不证明游戏有趣。

## 文件和边界

- `dist/engine.js`：两项能力、六种行动、四个条件机会、两种身份、资金结算与严格重放校验；纯函数，不调用随机或网络。
- `dist/story.js`：短开场、条件事件、练习/首次任务/重复任务/身份后的独立职责与回顾。
- `dist/app.js`：角色面板、行动、结算、成果、菜单、当前一局保存与恢复。
- `dist/styles.css`：克制的像素文字 RPG、响应式布局、键盘焦点与减少动画支持。
- `.openai/hosting.json`：复用原 Sites 项目身份与静态目录。

存档使用 `chengnan.growth.save.v2`，只存在当前浏览器；旧 `three-weekends.save.v1` 保留，不伪造迁移为新角色经历。结构化事件保留稳定 ID、事实、触发来源与当时文案，后续分享从实际记录读取。

首次直接开局，顶部游戏名进入菜单，可以换资金起点。数字键 1–6 可选择当前行动，Esc 关闭弹窗。重玩替换当前 v0.2 进度前先确认。

## 演示规则

默认 ¥480（另有 ¥180 起点），每周一次行动，共八次。每次已含 ¥80 日常开销。两项能力各 0–4，基础练习 +1；达到 2 出现独立任务，达到 4 且实际做过该任务，出现身份节点。普通任务不增加本领。

| 行动 | 净资金 | 成果 |
| --- | --- | --- |
| 整理书架 | +120 | 书店事务 +1 |
| 街巷速写 | −120 | 街巷创作 +1 |
| 独立看店 | +240 | 首次独立值班记录 |
| 招牌委托 | +120 | “早点见”招牌 |
| 策划书桌 | −80 | 书店搭档；以后负责书桌净 +280 |
| 制作小册 | −80 | 街巷画手；以后插画约稿净 +180 |

以上均为虚构游戏参数，不是经济统计；作品为本项目创作的静态样本，没有实时 AI 服务。最早第六周形成身份，再有两次使用机会。晚到的机会记录事实，但试玩第八周暂停，不补写未发生的经历。

## 字体与发布

本地提供 [TakWolf / Fusion Pixel Font](https://github.com/TakWolf/fusion-pixel-font) 2026.10.25 的 12px proportional 简体字形，OFL 与上游组件许可保留于 `dist/fonts/`。像素人物与成果以本项目 SVG 绘制。

Sites 使用独立部署源码仓库；`web/` 是本 GitHub 仓库内的同版应用源。部署时复制到 Sites 检出，使用 Sites source helper 同步并打包，再用原生发布工具部署。站点沿用原入口和访问范围；本地更改不会自动上线。
