# 三个周末

当前 MVP 的第一份可玩实现：克制的像素文字 RPG，短场景直接进入行动，选择后出现具体事件，下一回合记得上次留下的东西。单页、纯 HTML/CSS/JavaScript，无第三方运行依赖。源文件直接放在 `dist/`，无需构建。

## 本地运行

```sh
cd web
npm run dev
```

打开 `http://127.0.0.1:4173/`。需要 Python 3；游戏本身只在浏览器运行。

## 验证

```sh
cd web
npm test
```

测试使用 Node.js 自带测试运行器，覆盖两个处境的动作组合、资金不足、截止时机、不可重复结算、输入不可变、损坏与过期存档校验，以及场景是否回应实际行动。已完成桌面与 390×844 手机布局的浏览器走查。

## 演示规则

| 参数 | 值 |
| --- | --- |
| 周末数 | 3 |
| 有一点积蓄 | ¥480 |
| 刚付过房租 | ¥180 |
| 每周末固定开销 | ¥80 |
| 一次额外工作收入 | ¥200，扣除固定开销后净增 ¥120 |
| 一次项目材料费 | ¥60，加固定开销后净减 ¥140 |
| 小册 | 第一次投入留下素材，第二次四页成册，第三次精修后记 |
| 小展 | 第二个周末结束时，已成册则参加；后来完成也不补发参展记录 |

所有金额与处境均为虚构演示参数，不是经济或社会统计。游戏不计算人生分数。小册内容和画作是本项目制作的静态样本，不使用实时 AI 生成。

## 文件

- `dist/engine.js`：独立状态结算、实际事件记录、严格重放校验。
- `dist/app.js`：页面交互、本局保存与恢复、小册阅读。
- `dist/story.js`：已创作的短场景与行动后反馈；不修改规则，不调用实时模型。
- `dist/styles.css`：桌面与手机排版、键盘焦点及减弱动画支持。
- `tests/engine.test.mjs`、`tests/story.test.mjs`：共 31 项规则与叙事一致性检查。
- `.openai/hosting.json`：Sites 身份与静态目录配置。

存档仅存于当前浏览器的 localStorage，不上传人生记录；部署入口的访问控制由托管平台处理。重新开始会替换本局记录，界面会先确认。

首次访问默认进入第一幕；通过顶部游戏名打开菜单，可以换另一种资金开局。支持按钮操作与数字键 1 / 2，弹窗支持 Esc。

## 字体

使用 [TakWolf / Fusion Pixel Font](https://github.com/TakWolf/fusion-pixel-font) 2026.10.25 的 12px proportional 简体字形，字体在本站本地提供；OFL 与上游组件许可随 `dist/fonts/` 一同保留。像素人物与物品图由本项目以 SVG 制作。

## 发布

在线入口：[三个周末](https://three-weekends-yuki.yuki-uix.chatgpt.site/)。

Sites 使用独立部署源码仓库；`web/` 是本 GitHub 仓库内的同版应用源。部署时将其复制到 Sites 检出，使用 Sites 技能的 source helper 同步并打包，再通过原生发布工具部署。只更新本地文件不会自动上线。
