# Life Sim Product Study

一次对 [1in8b.life](https://1in8b.life/) 的产品拆解与独立复刻实验。

**当前试玩：[大学慢慢来 · 一个秋天](https://three-weekends-yuki.yuki-uix.chatgpt.site/)** · [实现与运行说明](web/README.md)

当前阶段关注：**在校园小事中长出本领、认识同伴，让过去的参与改变后来的方式，并留下真实的共同回忆。**

本项目通过体验走查、公开实现参考和独立原型，研究随机出生、人生事件与玩家选择。Sharing 已调整为后续补充功能；首版保留结构化事件记录，以支持将来的事件挑选和分享。

## 项目身份与当前状态

- 这是独立研究项目，与原作者没有隶属或合作关系。
- 复刻范围是产品机制与交互流程；实现、文案和视觉另行制作。
- 原站源码未公开；相关二创仓库只作为参考，不能视为官方实现。
- v0.1「三个周末」收到「不好玩，没有养成系的感觉」的直接试玩反馈。
- v0.2「城南八周」的升级路线仍被反馈为不够好玩，已转向轻松校园生活。
- 当前 v0.6 让早期选择改变之后的实际练法；相同日常投入会练出不同专长，并进入不同后续。保留日历、两件主动准备事项与最新在上的日志。v0.3 的每次强制成果与固定六次选择已退出当前入口。
- 用户明确选择养角色，并要求能力决定可以触发哪些事件。
- 下一轮方向已改为：中国背景、轻松的大学生活；求职主线移出范围，先以四年为样本，三年/五年留学制扩展边界。目前只开放入学后三个月试玩，完整四年内容与其他学制后置。
- 已确认的范围调整：sharing 后置，人生事件的持久记录纳入首版设计。
- 原先 20 项事件方案已后置，不是当前第一层的任务清单。
- 除上述已确认调整外，其余范围、时长、指标与技术方案仍为提案，等待讨论和验证。

## 当前可玩范围

一座虚构的中国校园，入学后的九月至十一月。选择一个持续的课余重心，日历独立前进；普通周记与校园变化自动经过，原三场校园剧情与两组主动准备后续在时间、专长和经历条件满足时暂停，每组每局至多一个版本，选择写回同一天的记录。记录与张罗随着实际投入渐渐熟练，认识的人和后续回响来自真实经历；玩家主动加星的记录才进入收藏。

支持暂停、倍速、快进至下个剧情、本地存档恢复与重玩。39 项日历、养成、历史分歧与旧存档迁移测试通过，覆盖三场剧情的 27 种选项组合；浏览器走查完成自动时间、重心切换、剧情暂停、拒绝参与、收藏筛选、刷新恢复与十一月底收束。这些检查保证流程可用，是否好玩仍需试玩。

## 研究原则

1. **区分证据与判断。** 原站实际行为、作者声明、二创实现和我们的提案分别记录。
2. **来源声明不等于数据核验。** 核验时记录字段、年份、单位、出处、处理方法和缺失值。
3. **国家均值不等于个人概率。** 模拟假设单独标注，不把游戏结果解释成真实人生预测。
4. **先保留人生经历。** 当前状态与已发生事件分别保存，后续再决定哪些值得分享和怎样呈现。
5. **代码生成后仍需验收。** 页面存在不代表路径可用，本地数据不代表跨用户社区已经完成。
6. **未来分享单独验证。** 点击分享不等于发送成功；届时区分曝光、分享操作、链接访问与新玩家开局。
