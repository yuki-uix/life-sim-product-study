# Life Sim Product Study

一次对 [1in8b.life](https://1in8b.life/) 的产品拆解与独立复刻实验。

**当前方向：中国背景、完整一生；本轮验证外省路线23—30岁的持续生活。** 页面仍能从出生走到85岁结束，但只有这一段接入了“安排生活 → 年度变化 → 按处境选择办法 → 承担后续”的循环。留本地路线及31岁之后大部分仍沿用既有叙事，不能据此宣称整个人生模拟已完成。

**[打开新版试玩](https://three-weekends-yuki.yuki-uix.chatgpt.site/life/)**。可从23岁的固定前情开始，也可从出生走到18岁选择去外省。结尾仍能挑选本局经历、填写自己的话并保存PNG卡片。**[上一版完整人生](https://three-weekends-yuki.yuki-uix.chatgpt.site/life-v1/)** 保留原存档的继续入口。

固定样本仍是陈知夏、2005年出生于澄江维修铺家庭，所有走法在2090年、85岁结束。这是虚构内容的对照条件，不是中国人口或寿命模型。

```mermaid
flowchart LR
    A[已实现：23岁临港生活] --> B[保持或调整重心与预约]
    B --> C[年份经过，时间与余裕改变]
    C --> D[29岁按准备选择处理办法]
    D --> E[30岁承担后续承诺]
    E --> F[接回既有晚年与真实记录卡片]
```

三种重心会持续，不要求每年重选，点击时不即时产生成果。每年可另约一件具体的事，实际占用空闲周末与备用金；周舟也有自己的工作，只有25—26岁这段排得出共同剪辑的时间。29岁仍会遇到同一处搬店与投稿冲突，准备、手头和实际合作经历改变处理办法与不可行原因。联名交片还要在30岁实际留时间履约。

当前规则检查共117项：15项新生活循环、13项完整一生和89项历史原型。原13项中的40种基线组合，以及准备充分时另验的32种后续组合，都不是独立人生篇数；新增年度安排也不只构成40种组合。检查通过不代表好玩已验证。本轮要看玩家能否理解眼下的取舍，并因为局面变化而维持或调整生活；若只快进等29岁按钮，循环仍未成立。

新存档使用 `china-life.save.v2`。上一版冻结在 `/life-v1/`，继续读取 `china-life.save.v1`，不覆盖旧人生，也不替旧经历补造新的投入或合作。精简分享卡继续只从实际记录取材。更多国家、随机出生和寿命、完整职业经济、自由社交网、并行同龄人及公开分享社区仍后置。

## 研究原则

- 这是独立研究，与原作者无隶属或合作关系。实现、文字和视觉独立制作，不包含原站源码或素材。
- 区分原站观察、作者声明、模型假设和我们自己的设计。原站声称使用公开统计，不等于本项目完成了资料核验。
- 当前人物、城市和未来事件均为虚构，不用国家均值解释个人命运，不伪造真实在线玩家或群体百分位。
- 人生回顾与分享卡只引用本局实际事实；收到视频不等于亲历，素材存在不等于作品完成或展出。
- 规则、分支与存档检查保证流程可用，不能单独证明趣味成立；点击保存或分享也不等于内容已发送或传播有效。
