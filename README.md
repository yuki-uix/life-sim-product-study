# Life Sim Product Study

一次对 [1in8b.life](https://1in8b.life/) 的产品拆解与独立复刻实验。

**当前 MVP：中国背景，完整一生。** 从一个具体的人生起点走到晚年与结束，普通生活自然经过，少数重要选择改变后来的人、地方和机会，最后由玩家挑选实际经历生成分享卡。

当前处于纸面内容与范围调整阶段。**完整一生尚未实现，现在线上仍为旧的八天校园原型。** 本轮不修改游戏代码或部署。

## 当前范围与内容

| 文档 | 用途与状态 |
| --- | --- |
| **[中国完整一生 MVP](docs/china-life-mvp.md)** | **当前范围的唯一入口：体验目标、首版边界、内容缺口、后置项目与验收** |
| **[两条完整纸面试玩](docs/china-life-paper-playthroughs.md)** | **同一出生卡、18岁后不同走法、后续回响与两张分享卡样稿** |
| [事件记录设计](docs/event-records.md) | 记录本局实际事实、亲历与来源，支撑首版回顾与卡片；复杂字段为扩展参考 |

两条样本都从陈知夏、2005年出生的澄江维修铺家庭开始。A在18岁去外省，经历迁居、同住与晚年回乡；B留本地，经历旧街采录、关系变化、社区小组和迟来的旅行。相同的老街改造发生在不同生活处境中。两条固定85岁结束，作为当前对照条件，不作为中国人口或寿命模型。

```mermaid
flowchart LR
    A[已完成纸面：共同起点] --> B[少数选择与普通生活]
    B --> C[多年后的具体回响]
    C --> D[人生回看与分享卡样稿]
    D --> E[下一步：补齐未选分支]
    E --> F[后续另行启动交互实现与首玩验证]
```

精简分享卡进入首版：从实际记录挑内容、可选个人感想、预览并保存图片。公开社区、真实在线人数、大量模板与商业化后置。随机出生卡数量、随机寿命、并行模拟人物、数值面板和固定单局时长尚未由这两条样本确定。

已写完整两条走法，不代表其他选择组合均已写完，更不代表好玩已验证。下一步先补齐已有选项的后续，检查玩家是否想知道后来、能否在意并认出回响、是否愿意回看或表达这一生。

## 研究原则

- 这是独立研究，与原作者无隶属或合作关系。实现、文字和视觉独立制作，不包含原站源码或素材。
- 区分原站观察、作者声明、模型假设和我们自己的设计。原站声称使用公开统计，不等于本项目完成了资料核验。
- 当前纸面人物和未来事件均为虚构，不用国家均值解释个人命运，不伪造真实在线玩家或群体百分位。
- 人生回顾与分享卡只引用本局实际事实；收到视频不等于亲历，素材存在不等于作品完成或展出。
- 规则、分支与存档检查保证流程可用，不能单独证明趣味成立；点击保存或分享也不等于内容已发送或传播有效。
