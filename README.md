# Life Sim Product Study

一次对 [1in8b.life](https://1in8b.life/) 的产品拆解与独立复刻实验。

我们关注一个具体问题：**一段随机生成的人生，怎样变成用户愿意分享、朋友看完也想参与的内容？**

本项目通过体验走查、公开实现参考和独立原型，研究随机出生、人生事件、结果卡片与分享回流之间的关系。

## 项目身份与当前状态

- 这是独立研究项目，与原作者没有隶属或合作关系。
- 复刻范围是产品机制与交互流程；实现、文案和视觉另行制作。
- 原站源码未公开；相关二创仓库只作为参考，不能视为官方实现。
- 当前完成的是项目立项与 MVP 草案，尚未开始编写游戏。
- MVP 中的范围、时长、指标与技术方案均为提案，等待讨论和验证。

## 建议的第一阶段

用单语言、少量国家和事件，跑通 **出生 → 短人生 → 结局 → 分享 → 朋友开局**。

第一轮建议为 5 个国家、约 30 条事件模板、3–5 分钟的一生、出生与结局两种分享卡。国家数量、事件数量和时长均是缩小实验范围的设计选择，不是原站配置。

研究原型与公开实验分开验收：前者验证人生与结果是否成立；后者验证真实设备上的分享、链接预览和可归因的回流。具体边界见 MVP 草案。

## 研究原则

1. **区分证据与判断。** 原站实际行为、作者声明、二创实现和我们的提案分别记录。
2. **来源声明不等于数据核验。** 核验时记录字段、年份、单位、出处、处理方法和缺失值。
3. **国家均值不等于个人概率。** 模拟假设单独标注，不把游戏结果解释成真实人生预测。
4. **点击分享不等于发送成功。** 分开统计卡片曝光、分享操作、链接访问与新玩家开局。
5. **代码生成后仍需验收。** 页面存在不代表路径可用，本地数据不代表跨用户社区已经完成。
